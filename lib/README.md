# JUnit dependency

The application requires only JDK 17. Tests additionally require the official
`junit-platform-console-standalone-1.13.4.jar`, which includes JUnit Jupiter 5.13.4.
Place the downloaded JAR in this directory. It is intentionally excluded from Git.

Official artifact:
https://repo.maven.apache.org/maven2/org/junit/platform/junit-platform-console-standalone/1.13.4/junit-platform-console-standalone-1.13.4.jar

Documentation:
https://docs.junit.org/5.13.4/user-guide/#running-tests-console-launcher

The artifact was not downloaded in the preparation environment because external
network downloads failed. No replacement or imitation of JUnit is included.
